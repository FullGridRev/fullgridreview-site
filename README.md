# fullgridreview.com

Website for The Full Grid Review, hosted free on Netlify from this repository.

- `index.html` is the live page. It is generated: edit `Main.dc.html` (the design file), then run `python3 build.py`.
- `logo.webp`, `favicon.png`, `apple-touch-icon.png`, `og-image.jpg` are the site images.
- The FGR Weekly signup box is a Beehiiv embed added by `build.py`.
